# AI Developer Ranking & Benchmark Dashboard

Система еженедельного независимого мониторинга видимости и репутации застройщиков в нейросетях (**ChatGPT**, **Gemini**, **Perplexity**).

## Архитектура системы

1. **`run_audit.py` (Оркестратор):**
   - Запускает 3 комплексных аудита по расписанию раз в неделю.
   - Опрашивает **Google Gemini** через бесплатный официальный API с живым поиском Google Search Grounding.
   - Опрашивает **ChatGPT** и **Perplexity** через изолированный профиль Google Chrome (`browser_data`).
2. **`analyzer.py` (NLP-скоринг):**
   - Извлекает упоминания компаний, статус прямых рекомендаций, отзывы и стоп-факторы (судебные процессы, задержки).
   - Рассчитывает **AI Visibility & Trust Index**: 40% Share of Voice + 45% Рекомендации - Штрафы за риски.
3. **`storage.py` (БД и экспорт):**
   - Сохраняет историю в SQLite (`rankings.db`) для вычисления динамики ранга (▲ / ▼).
   - Экспортирует `rankings_latest.json` для сайта-дашборда.
4. **`index.html` (Сайт-дашборд):**
   - Публичная интерактивная витрина рейтинга с фильтрами по регионам.
   - Карточки детального разбора сильных сторон и стоп-факторов девелопера.
   - **B2C-воронка:** Лид-форма для покупателей на подбор безопасного объекта из Топ-5.
   - **B2B-воронка:** Лид-форма для девелоперов на заказ аудита и вывода в топ (GEO-услуга).

## Быстрый старт в 3 шага:

### Шаг 1: Разовая авторизация
Запустите `1_setup_auth.bat`. Откроется окно Chrome:
- Войдите в свои аккаунты на `chatgpt.com` и `perplexity.ai`.
- Нажмите Enter в черном окне консоли. Профиль сохранится навсегда.

### Шаг 2: Еженедельный запуск
Запустите `2_run_weekly_audit.bat`:
- Скрипт сам задаст 3 комплексных промпта в новые чаты нейросетей, соберет ответы, пересчитает баллы и обновит рейтинг.

### Шаг 3: Просмотр дашборда
Запустите `3_open_dashboard.bat` или откройте `index.html` в любом браузере.
